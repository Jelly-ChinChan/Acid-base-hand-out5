🔥 本質探討：為什麼 HF 解離度低？
• 解離反應式與熱效應：
H–F ⇌ H⁺ ＋ F⁻ ,　ΔH > 0 (吸熱)
• 鍵能強弱關鍵：
F 原子半徑極小，H–F 鍵能極大（鍵極為牢固不易斷裂），相比之下 H–Cl 鍵能較弱容易斷鍵完全解離！
• 水合焓與熵效應：F⁻ 離子半徑小、電荷密度極高，使水分子高度有序排列，解離過程熵值劇減（$\Delta S < 0$），導致 $\Delta G > 0$ 解離度極低。
💡 展哥口訣：強酸稀釋 10 倍 pH 必加 1；弱酸稀釋 10 倍 pH 僅加 0.5！

📌 展哥重點：弱酸溶液中，酸的主要存在形式依然是「未解離的酸分子」！
三、平衡推導與奧士華定律 Ka 近似與公式嚴密推導
1. HA 解離 ICE 平衡三部曲
HA ⇌ H⁺ ＋ A⁻　(平衡常數 Ka)
狀態 HA H⁺ A⁻
初 (I) [HA]₀ (或記作 C) 0 0
變 (C) －x ＋x ＋x
平 (E) [HA]₀ － x x x
Ka ＝ [H⁺][A⁻] / [HA] ＝ x² / ([HA]₀ － x)
2. 關鍵條件與展哥配對法
① 若 Ka 極大：則 x 極大，$K_a \rightarrow \infty$，即為強酸完全解離！
② 若 Ka 很小：則 x 很小，分母可近似：
[HA]₀ － x ≈ [HA]₀
因此：Ka ≈ x² / [HA]₀
👉 解出 [H⁺]：
x ＝ [H⁺] ＝ √( [HA]₀ · Ka ) ＝ √( C · Ka )
(展哥口訣：「配配配、查查查」，開根號即得氫離子濃度！)
3. 解離度 α (奧士華稀釋定律)
• 定義：α ＝ [H⁺] / [HA]₀ ＝ x / C
• 代入 x 公式：
α ＝ √( [HA]₀ · Ka ) / [HA]₀ ＝ √( Ka / [HA]₀ ) ＝ √( Ka / C )
• 雙變因掌控（大考必考）：
👉 當溫度 ↑ 時（吸熱反應 $K_a \uparrow$），解離度 α ↑
👉 當初始酸濃度 [HA]₀ ↑ (變濃) 時，解離度 α ↓（越濃越不易解離；越稀釋 α 越大！）

❓ 為什麼弱酸加水時 pH 上升較慢？
• 強酸稀釋 10 倍：
$[H^+] = [HA]_0 = C$；體積增為 10 倍，濃度變為 $1/10$：
$\Delta \text{pH} = -\log(1/10) =$ ＋ 1
• 弱酸稀釋 10 倍：
$[H^+] = \sqrt{C K_a} \propto \sqrt{C}$；體積增為 10 倍，$C$ 變為 $1/10$：
$[H^+]' = \sqrt{\frac{C}{10} \cdot K_a} = \frac{1}{\sqrt{10}} [H^+]$
$\Delta \text{pH} = -\log\left(\frac{1}{\sqrt{10}}\right) = \log\sqrt{10} = \frac{1}{2} \log 10 =$ ＋ 0.5！
🎯 展哥核心結論：
弱酸稀釋時，平衡向右移動產生額外的 H⁺ 緩解濃度下降，故 pH 只上升 0.5！

5% 近似規則 · 奧士華稀釋極限 · 熱力學凡特何夫方程式 · 勒沙特列微觀商數 Q
📌 A. 什麼時候「$[HA]_0 - x \approx [HA]_0$」近似會破功？（5% 規則）

課堂推導中令分母 $[HA]_0 - x \approx [HA]_0$，在化學計量學上有其極嚴格的前提條件：

  • 5% 檢驗準則 (5% Rule)：只有當解離度 $\alpha = \frac{x}{[HA]_0} \le 5\%$（即 $0.05$）時，分母忽略 $x$ 所造成的誤差才能被容許在 $5\%$ 以內。
  • 何時不可忽略？：當酸極度稀薄（例如 $[HA]_0 < 10^{-4}\text{ M}$）或 $K_a$ 偏大（如草酸 $K_{a1} = 5.9 \times 10^{-2}$）時，$\alpha$ 會遠大於 5%，此時絕對不能省略分母的 $x$，必須回歸解一元二次方程式：
    $x^2 + K_a x - K_a [HA]_0 = 0 \;\Rightarrow\; x = \frac{-K_a + \sqrt{K_a^2 + 4K_a [HA]_0}}{2}$
📌 B. 【奧士華極限迷思】：若酸無限加水稀釋，pH 會無限上升變成鹼性嗎？

由公式 $\Delta \text{pH} = +0.5$，若將弱酸連續稀釋 $10^6$ 倍，pH 是否會一路攀升到 8 或 9？

• 迷思破除：酸溶液無論如何加水稀釋，pH 絕對不可能超過 7！
• 微觀真相（水的自解離補償）：當酸極度稀釋至 $[H^+] \le 10^{-6}\text{ M}$ 時，來自水本身的自解離（$H_2O \rightleftharpoons H^+ + OH^-$）將成為不可忽視的主導力量！
• 極限值歸宿：在 25°C 下，無限加水稀釋的極限狀態就是「純水」，因此不論是強酸還是弱酸，pH 上限漸近線均為 7.0（常溫中性）！
📌 C. 【反應商 Q 深度剖析】：加水瞬間，分子與離子發生了什麼事？

為什麼「加水稀釋」平衡一定朝向粒子數多的一方移動？從反應商 $Q$ 即可得證：

• 設弱酸溶液瞬間加水體積膨脹為 $n$ 倍，則各物種濃度瞬間均稀釋為原來的 $1/n$：
$Q = \frac{([H^+]/n)([A^-]/n)}{([HA]/n)} = \frac{1}{n} \cdot \frac{[H^+][A^-]}{[HA]} = \frac{1}{n} K_a < K_a$
• 因為加水瞬間 $Q < K_a$，系統被迫向右移動以重新達成平衡！這就是為什麼加水一定能迫使弱酸進一步解離、解離度 $\alpha$ 必然上升的本質原因！
📌 D. 【熱力學深究】：溫度上升對弱酸解離度 α 的真正影響

黑板上特別註記「當溫度 $\uparrow$ 時，解離度 $\alpha \uparrow$」，背後的熱力學基礎：

• 大多數弱酸（如 HF、醋酸）在常溫下的水合電離反應主要為吸熱反應 ($\Delta H > 0$)。
• 依凡特何夫方程式（van 't Hoff equation）：
$\ln\left(\frac{K_{a2}}{K_{a1}}\right) = \frac{\Delta H^\circ}{R} \left(\frac{1}{T_1} - \frac{1}{T_2}\right)$
• 溫度升高使平衡常數 $K_a$ 實質增大。再由 $\alpha = \sqrt{K_a / C}$，當 $K_a$ 增大時，解離度 $\alpha$ 必然顯著提升！
