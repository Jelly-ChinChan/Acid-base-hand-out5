一、強酸與弱酸特性對比 HCl vs HF 關鍵三問
1. 核心性質三指標對比
比較指標 HCl (強酸) HF (弱酸)
解離程度 (α) 100% 10% (<<100%)
稀釋成 10 倍體積
(稀釋效應)		 原 pH ＋ 1 原 pH ＋ 0.5
加水稀釋時
解離度變化		 不變 解離度上升 ↑
🔥 本質探討：為什麼 HF 解離度低？
• 解離反應式與熱效應：
H–F ⇌ H⁺ ＋ F⁻ ,　ΔH > 0 (吸熱)
• 鍵能強弱關鍵：
F 原子半徑極小，H–F 鍵能極大（鍵極為牢固不易斷裂），相比之下 H–Cl 鍵能較弱容易斷鍵完全解離！
• 水合焓與熵效應：F⁻ 離子半徑小、電荷密度極高，使水分子高度有序排列，解離過程熵值劇減，導致解離度極低。
💡 展哥口訣：強酸稀釋 10 倍 pH 必加 1；弱酸稀釋 10 倍 pH 僅加 0.5！
二、微觀粒子圖像與質量守恆 燒杯粒子數定量解析
【板書微觀燒杯圖解】：投入 100 個分子後的解離樣貌
⚛️ 原子質量守恆（Mass Balance）
• HCl 強酸系統（氯原子守恆）：
[HCl]₀ ＝ [Cl⁻] ＋ [HCl]
👉 相當於 100 ＝ 100 ＋ 0（因為強酸 100% 完全解離，[HCl] ＝ 0！）
• HF 弱酸系統（氟原子守恆）：
[HF]₀ ＝ [F⁻] ＋ [HF]
👉 相當於 100 ＝ 10 ＋ 90（已解離離子 ＋ 未解離分子）
• CH₃COOH 弱酸系統（碳原子守恆）：
[CH₃COOH]₀ ＝ [CH₃COO⁻] ＋ [CH₃COOH]
👉 相當於 100 ＝ 1 ＋ 99
💡 展哥點撥：[HCl]₀ 與 [HCl] 到底差在哪？
• [HCl]₀（初始配製濃度）：代表當初丟進水裡的總量（相當於 100 個分子）。
• [HCl]（平衡分子濃度）：代表解離後水中仍以 HCl 分子形式存在的量。
👉 大考常考觀念：強酸因完全解離，平衡時水中共價分子濃度 [HCl] ＝ 0，故質量守恆式中 [HCl]₀ 直接等於 [Cl⁻] ＝ [H⁺]！
📌 展哥重點：弱酸溶液中，酸的主要存在形式依然是「未解離的酸分子」！
三、平衡推導與奧士華定律 Ka 近似與公式嚴密推導
1. HA 解離 ICE 平衡三部曲
HA ⇌ H⁺ ＋ A⁻　(平衡常數 Ka)
狀態 HA H⁺ A⁻
初 (I) [HA]₀ (或 C) 0 0
變 (C) －x ＋x ＋x
平 (E) [HA]₀ － x x x
Ka ＝ [H⁺][A⁻] / [HA] ＝ x² / ([HA]₀ － x)
2. 關鍵條件與展哥口訣：氫乘
① 若 Ka 極大：則 x 極大，Ka → ∞，即為強酸完全解離！
② 若 Ka 很小：則 x 很小，分母可近似：
[HA]₀ － x ≈ [HA]₀
因此：Ka ≈ x² / [HA]₀
👉 解出 [H⁺]：
[H⁺] ＝ √( C × Ka ) ＝ √( [HA]₀ · Ka )
💡 展哥口訣：「氫乘」（[氫離子] ＝ 根號 C × Ka，開根號兩者相乘！）
3. 解離度 α% 與展哥口訣：趴下C
• 定義：α ＝ [H⁺] / [HA]₀ ＝ x / C
• 代入 [H⁺] 公式化簡：
α ＝ √( Ka / C ) ＝ √( Ka / [HA]₀ )
💡 展哥口訣：「趴下 C」（解離度趴數 α% ＝ 根號 Ka 除以 C，C 在分母趴在下面！）
• 雙變因掌控（大考必考）：
👉 當溫度 ↑ 時（吸熱反應 Ka ↑），解離度 α ↑
👉 當酸濃度 C ↑ (變濃，分母大) 時，解離度 α ↓（越濃越不易解離；越稀釋 α 越大！）
四、圖形解析與稀釋效應 板書三大圖形真實重現
1. 解離度 α vs Ka（正相關）
• Ka 較大的弱酸更易解離：HF (Ka大) > CH₃COOH (Ka小)
2. 解離度 α vs [HA]₀（負相關）
• [HA]₀ 較大的弱酸越不易解離；越加水稀釋，解離度 α 越大！
3. pH vs 加水稀釋（弱酸上升較慢）
• 弱酸加水時 pH 上升較慢（稀釋促進解離補償 H⁺）
❓ 為什麼弱酸加水時 pH 上升較慢？
• 強酸稀釋 10 倍：
[H⁺] ＝ [HA]₀ ＝ C；體積變 10 倍，濃度變為 1/10：
ΔpH ＝ －log(1/10) ＝ ＋ 1.0
• 弱酸稀釋 10 倍：
[H⁺] ＝ √(C · Ka) ∝ √C；體積變 10 倍，C 變為 1/10：
[H⁺]' ＝ √(C/10 · Ka) ＝ (1/√10) · [H⁺]
ΔpH ＝ －log(1/√10) ＝ log√10 ＝ (1/2) log 10 ＝ ＋ 0.5！
🎯 展哥核心結論：
弱酸稀釋時，平衡向右移動產生額外的 H⁺ 緩解稀釋衝擊，故 pH 只上升 0.5！

5% 近似規則 · 奧士華稀釋極限 · 熱力學凡特何夫方程式 · 勒沙特列微觀商數 Q
📌 A. 什麼時候「[HA]₀ － x ≈ [HA]₀」近似會破功？（5% 規則）

課堂推導中令分母 [HA]₀ － x ≈ [HA]₀，在化學計量學上有其極嚴格的前提條件：

  • 5% 檢驗準則 (5% Rule)：只有當解離度 α ＝ x / [HA]₀ ≤ 5%（即 0.05）時，分母忽略 x 所造成的誤差才能被容許在 5% 以內。
  • 何時不可忽略？：當酸極度稀薄（例如 [HA]₀ < 10⁻⁴ M）或 Ka 偏大（如草酸 Ka1 = 5.9 × 10⁻²）時，α 會遠大於 5%，此時絕對不能省略分母的 x，必須回歸解一元二次方程式：
    x² ＋ Ka x － Ka [HA]₀ ＝ 0  ⇒  x ＝ [ －Ka ＋ √(Ka² ＋ 4Ka[HA]₀) ] / 2
📌 B. 【奧士華極限迷思】：若酸無限加水稀釋，pH 會無限上升變成鹼性嗎？

由公式 ΔpH ＝ ＋0.5，若將弱酸連續稀釋 10⁶ 倍，pH 是否會一路攀升到 8 或 9？

• 迷思破除：酸溶液無論如何加水稀釋，pH 絕對不可能超過 7！
• 微觀真相（水的自解離補償）：當酸極度稀釋至 [H⁺] ≤ 10⁻⁶ M 時，來自水本身的自解離（H₂O ⇌ H⁺ ＋ OH⁻）將成為不可忽視的主導力量！
• 極限值歸宿：在 25°C 下，無限加水稀釋的極限狀態就是「純水」，因此不論是強酸還是弱酸，pH 上限漸近線均為 7.0（常溫中性）！
📌 C. 【反應商 Q 深度剖析】：加水瞬間，分子與離子發生了什麼事？

為什麼「加水稀釋」平衡一定朝向粒子數多的一方移動？從反應商 Q 即可得證：

• 設弱酸溶液瞬間加水體積膨脹為 n 倍，則各物種濃度瞬間均稀釋為原來的 1/n：
Q ＝ ( [H⁺]/n · [A⁻]/n ) / ( [HA]/n ) ＝ (1/n) · ( [H⁺][A⁻] / [HA] ) ＝ (1/n) · Ka < Ka
• 因為加水瞬間 Q < Ka，系統被迫向右移動以重新達成平衡！這就是為什麼加水一定能迫使弱酸進一步解離、解離度 α 必然上升的本質原因！
📌 D. 【熱力學深究】：溫度上升對弱酸解離度 α 的真正影響

黑板上特別註記「當溫度 ↑ 時，解離度 α ↑」，背後的熱力學基礎：

• 大多數弱酸（如 HF、醋酸）在常溫下的水合電離反應主要為吸熱反應 (ΔH > 0)。
• 依凡特何夫方程式（van 't Hoff equation）：
ln( Ka2 / Ka1 ) ＝ (ΔH° / R) · ( 1/T₁ － 1/T₂ )
• 溫度升高使平衡常數 Ka 實質增大。再由 α ＝ √(Ka / C)，當 Ka 增大時，解離度 α 必然顯著提升！
